# Smart Bus Seva

Smart Bus Seva is an AI-powered public transportation management system designed to improve urban bus services through real-time monitoring and intelligent analytics.

## Features

* Real-time bus tracking
* Passenger crowd monitoring
* AI-based demand forecasting
* Route optimization dashboard
* Smart dispatch recommendations
* Bus stop arrival display
* Voice announcements in multiple languages
* Admin control dashboard

## Technologies Used

* Python
* Flask
* HTML5
* CSS3
* JavaScript
* Leaflet.js
* Chart.js

## Installation

Clone the repository:

```bash
git clone <repository-url>
cd Smart-Bus-Seva
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python smartbus_ai.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```
